# SPEC-014 — Session Engine
Version: 1.0
Status: Approved
Category: Core System Specification

---

# Purpose

The Session Engine manages the continuity of every creative experience inside Sonic AI V3.

It does not manage projects.

It manages time.

Every interaction becomes part of an evolving creative history.

The Session Engine ensures Sonic always understands what happened previously, what is happening now, and what should happen next.

---

# Philosophy

A project is permanent.

A session is temporary.

Projects contain sessions.

Sessions contain creative work.

---
