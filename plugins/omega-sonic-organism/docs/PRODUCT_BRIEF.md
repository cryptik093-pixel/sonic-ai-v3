# Current product scope

OMEGA SONIC ORGANISM 1.0.0-rc.2 is an unqualified Windows x64 VST3 instrument candidate. See ARCHITECTURE.md for the implemented shared synthesis architecture, USER_MANUAL.md for controls and RELEASE_STATUS.md for evidence-bound gates. The original MASTER_BLUEPRINT.md, parameter contracts and factory sound specification remain preserved.

Native VSTGUI, 30 embedded/exported patches, strict JSON exchange, MIDI/automation scheduling, sound/state tests and Windows installer tooling are implemented. Commercial approval requires CPU qualification, full editor interaction, FL Studio scan/play/save-reopen/export, independent build reproduction and human sound-quality acceptance. No current document should imply those gates passed because the source exists or a headless render succeeded.
