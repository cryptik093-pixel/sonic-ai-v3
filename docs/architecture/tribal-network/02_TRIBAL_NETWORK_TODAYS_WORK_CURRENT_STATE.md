## 3. Today's working architecture

The current conceptual architecture can be represented as four cooperating layers:

1. Dashboard - persistent operating shell that surfaces what matters now and routes the member into work.
2. Stations - focused environments for creating, planning, collaborating, learning, releasing, managing assets, and pursuing opportunities.
3. Tribal Network - structured private record that organizes identity, projects, career development, contribution, services, collaboration, and history.
4. Sonic Intelligence - reasoning/memory layer that connects evidence and context across those systems.

## 5. What should be built next, in order

1. Audit the actual existing Tribe implementation and label every current feature VERIFIED, PARTIAL, UNKNOWN, or NOT STARTED.
2. Define the canonical data model for Member, Project, Release, Asset, Evidence, Collaboration, Service, Skill/Practice, Season, and Event.
3. Build the minimum Living Profile against real structured objects rather than static mock data.
4. Build one complete Project Object workflow from creation -> work -> collaboration -> release/outcome -> profile history.
5. Connect one additional station to that project workflow and prove that activity can be electronically pressed into the network automatically.
6. Add a first useful metrics/evidence summary that helps the creator understand progress without gamifying vanity.
7. Introduce Sonic Intelligence only after the underlying record is reliable enough to provide grounded context.
8. Add the soft initiation/reflection layer after genuine project and practice evidence exists to reflect upon.

## 6. Today's acceptance criteria

- The team can explain Tribal Network without calling it merely a profile, EPK, or creator social network.
- The private-first audience and guild role are explicit.
- The phrase "electronic pressing" has a precise working meaning.
- Dashboard, Stations, Tribal Network, and Sonic Intelligence have distinct responsibilities.
- The initiation concept is recorded as a soft system principle rather than overbuilt doctrine.
- A permanent final-state benchmark now exists outside the daily/current-state record.
