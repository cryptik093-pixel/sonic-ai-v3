# Cleanup, character and movement implementation

These modules implement Tasks 5 and 6 using the production physical-unit snapshot. `prepare` validates 8–384 kHz and may allocate. `reset` is an offline lifecycle operation. Per-sample processing and parameter changes contain no heap operations, locks, file access or host calls. A parent engine applies branch levels and the single wet pan/width stage.

The gate detector is stereo-linked max absolute peak, instantaneous on rising peaks and a 1 ms exponential decay. Threshold opens; threshold minus 3 dB starts the hold countdown. Returning into the hysteresis band while open reloads the hold. Hold is rounded to an integer sample count. Gain in dB moves exponentially toward zero on attack and negative attenuation on release. Each time control denotes one exponential time constant: 63.2% movement in one tau and more than 99% in five tau. Gate enable crossfades over a 20 ms time constant; spatial tails are downstream and independent.

The de-esser uses identical one-pole low-pass coefficients in L/R and residual high bands. A linked high-band peak envelope uses 1/80 ms attack/release. The reduction law is the specified 0.75 dB-per-dB slope, capped by Max Reduction, with another 1 ms gain smoother. Processing uses `input + (gain-1)*high` to remain exactly neutral at zero reduction. `highBand()` exposes the diagnostic signal; the parent routes Listen through output protection. Frequency and enable transitions use 20 ms exponential smoothing. Diagnostic high-band samples are bounded to finite float range while calculations and envelopes use double precision.

Character uses independent stereo 12 dB/octave Butterworth HP then LP, each with smoothed cutoff and a 20 ms enable crossfade. Coefficients refresh every 16 samples, independent of callback boundaries. All four saturation outputs are evaluated and mode weights crossfade with 20 ms smoothing; each nonlinear curve has its own 10 Hz DC blocker so changing modes does not share incompatible DC state. Clean bypasses saturation/DC processing and ignores Drive. Trim follows shaping. There is no oversampling or loudness matching. Extreme finite output conversions clamp to finite float range; this is numerical containment, not a substitute for the final limiter.

Movement owns two 50 ms buffers, allocated once during prepare. Double and chorus independently read fractional taps with linear interpolation. Sources retain channel separation; no hidden dry voice or branch gain is added. Double phases begin at 0/pi/2 and chorus phases at 0/pi/2. LFO phases advance once per sample and reset only on lifecycle reset or completed bounded clear. Delay/depth/rate and module-enable changes smooth with 20 ms time constants. Read delays clamp to at least one sample. At 96 kHz storage is approximately 38.5 kB per engine.

`Movement::beginClear` starts a silent incremental clear. Each `clearStep(maxWrites)` writes at most that number of individual floats (not stereo frames). Processing is muted and does not write the ring during clearing. Completion resets only the small state; a callback never invokes bulk reset. `allocatedBytes()` reports vector storage capacity, excluding the containing object.

Tests are defined in CleanupTests, CharacterTests and MovementTests. Actual execution results belong in the coordinator's verification record. Numerical curve/filter/delay tests do not establish perceived sound quality. Hard/asymmetric 44.1 kHz aliasing fixtures and owner vocal listening remain PENDING until rendered/analyzed/auditioned by an available path.
