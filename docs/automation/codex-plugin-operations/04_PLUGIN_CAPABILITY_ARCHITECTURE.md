# Plugin Capability Architecture

## Purpose
Treat plugins as reusable capability packages rather than isolated integrations.

## Omega House Operations concept

```text
OMEGA HOUSE OPERATIONS PLUGIN
|
+-- Skills
|   +-- sonic-repo-guardian
|   +-- sonic-feature-builder
|   +-- audio-product-packager
|   +-- shopify-product-launch
|   +-- cro-auditor
|   +-- seo-optimizer
|   +-- content-generator
|   +-- release-manager
|   +-- metadata-normalizer
|   +-- producer-intelligence
|
+-- Connected capabilities
    +-- GitHub
    +-- Shopify
    +-- analytics
    +-- email
    +-- content systems
    +-- Sonic MCP
```

## Architectural rule
A plugin/skill should carry repeatable operating doctrine so every agent does not need Omega House procedures re-explained from scratch.
