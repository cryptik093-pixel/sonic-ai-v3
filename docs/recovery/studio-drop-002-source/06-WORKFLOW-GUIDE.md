## 1. Purpose

This guide explains how to turn the included production assets into usable musical material inside a DAW.

The package is designed around three primary asset classes:

- **MIDI** — editable musical instructions for reconstruction and rearrangement.
- **Melody** — the melodic source material for direct use, editing, resampling, and inspiration.
- **Stems** — separated musical components that allow selective arrangement, processing, layering, and reconstruction.

The goal is not to prescribe one production method. The goal is to provide a repeatable path from **source material → creative manipulation → original production**.

## 3. Recommended First-Run Workflow

### Phase A — Listen

1. Load the supplied melodic material into the DAW.
2. Listen to the material without processing it first.
3. Identify the musical role you want to preserve: melody, harmony, rhythm, texture, motif, or atmosphere.
4. Decide whether the source should remain recognizable or become raw material for reconstruction.

### Phase B — Reconstruct

Choose one starting point:

- **MIDI-first:** begin with editable musical information.
- **Melody-first:** begin with the rendered melodic source.
- **Stem-first:** isolate the musical components you want to rebuild around.

### Phase C — Transform

Apply creative changes such as:

- transposition where musically appropriate;
- timing edits;
- note editing and velocity changes for MIDI;
- chopping and rearrangement;
- looping and variation;
- filtering and EQ;
- saturation or distortion;
- delay and reverb;
- modulation;
- pitching or time manipulation where supported by the DAW;
- layering with newly created material;
- resampling into new audio material.

### Phase D — Build

Add your own production elements around the transformed source:

- drums;
- bass;
- 808 or low-frequency elements;
- additional melodies;
- counter-melodies;
- transitions;
- vocals;
- textures and effects;
- arrangement changes.

### Phase E — Make It Yours

Treat the supplied material as a production foundation, not a finished identity.

Create meaningful transformation through arrangement, sound selection, performance, processing, layering, resampling, or new composition. Preserve project organization so the creative decisions remain reproducible.

## 4. MIDI Workflow

MIDI provides the highest level of musical editability in the package.

### Basic workflow

1. Import the MIDI into the DAW.
2. Assign an instrument appropriate to the musical role.
3. Confirm the imported notes and timing.
4. Edit notes, velocities, timing, articulation, or voicing.
5. Replace the instrument with your own sound choice.
6. Process the resulting instrument track.
7. Arrange repetitions and variations into the song structure.

### Reconstruction workflow

Use MIDI as a blueprint rather than a final performance:

```text
MIDI
  ↓
Instrument Selection
  ↓
Note / Timing Editing
  ↓
Sound Design
  ↓
Processing
  ↓
Arrangement
  ↓
Original Production
```

This path is especially useful when the producer wants to preserve the underlying musical idea while changing its sonic identity.

## 5. Melody Workflow

The melody can function as:

- a direct musical layer;
- a reference for rebuilding the idea with another instrument;
- a resampling source;
- a texture or atmospheric element;
- a starting point for variation;
- a compositional prompt.

### Transformation path

```text
Melody
  ↓
Chop / Edit / Re-time
  ↓
Pitch / Processing Decisions
  ↓
Layer or Resample
  ↓
Rearrange
  ↓
New Musical Context
```

When using the melody directly, build supporting elements around it so that the final production develops its own arrangement and sonic character.

## 6. Stem Workflow

Stems provide control over individual components of the production.

### Basic workflow

1. Import the required stems into separate tracks.
2. Name or organize tracks according to their semantic roles.
3. Mute components that are not needed.
4. Process individual components independently.
5. Rearrange or repeat sections.
6. Layer new instruments or samples around the selected components.
7. Resample processed combinations when useful.
8. Build a new arrangement from the selected material.

### Stem reconstruction concept

```text
STEMS
  ↓
Selective Isolation
  ↓
Independent Processing
  ↓
Recombination
  ↓
New Layers
  ↓
Arrangement
  ↓
New Production
```

This workflow is intended to make the source material accessible to producers with different production styles and DAW workflows.

## 7. Creative Reconstruction Paths

### Path 1 — Preserve the motif

Keep the central musical idea recognizable while changing instrumentation, drums, arrangement, and mix treatment.

### Path 2 — Flip the source

Chop, reverse, re-time, pitch, filter, resample, and rearrange selected material to create a substantially different musical context.

### Path 3 — Layer the source

Use selected source elements as one layer inside a larger original composition.

### Path 4 — Recompose from MIDI

Use the MIDI as a starting blueprint, then alter voicing, rhythm, instrumentation, and arrangement.

### Path 5 — Build from stems

Select only the components that serve the new production and replace the rest with original material.

### Path 6 — Resample

Process a source, record or render the result, then treat the new render as a production element for further editing.

For deeper reconstruction, use a staged workflow:

  ↓

  ↓

  ↓

At each stage, retain enough project organization to reproduce the creative decision.

### Recommended advanced practice

- Keep source and transformed versions distinguishable.
- Use descriptive track names.
- Preserve the original material before destructive processing.
- Save meaningful production milestones.
- Record major transformations when provenance matters.
- Do not remove license or certification documentation from the delivered package.

## 9. Accessibility & Troubleshooting

### If the MIDI does not load

- Verify the file was imported through the DAW's MIDI workflow rather than treated as audio.
- Confirm the MIDI file is not being opened by an incompatible application.
- Try importing into a new empty project.

### If audio is missing

- Confirm the source file was copied completely.
- Check the DAW's media/file browser for missing-file warnings.
- Re-link files without renaming the original source unless necessary.

### If timing feels incorrect

- Confirm the project tempo and time signature settings.
- Check whether the DAW interpreted the source tempo as expected.
- Verify that imported audio is being treated according to its actual timing information.

### If the producer wants a different sound

That is expected. Replace the instrument, process the audio, layer new sounds, or reconstruct the idea from MIDI/stems.

### If a rights question arises

Stop and consult the included license. Do not infer commercial permissions from marketing copy, this workflow guide, or a visual claim on the artwork.

## 11. Creator DNA Evidence

A producer workflow can generate useful evidence about creative behavior without treating a single action as a permanent preference.

Potential evidence signals include:

- preferred asset class;
- recurring transformation methods;
- instrument or sound-selection patterns;
- arrangement behavior;
- processing tendencies;
- resampling frequency;
- layering behavior;
- repeated workflow sequences;
- creative intent when explicitly provided by the producer.

Sonic AI V3 should treat these as evidence with provenance and confidence, not as unsupported assumptions.

### Evidence state model

```text
OBSERVED
   ↓
CAPTURED
   ↓
VALIDATED
   ↓
WEIGHTED
   ↓
PERSISTED
   ↓
RETRIEVABLE CREATOR DNA EVIDENCE
```

Repeated behavior may increase confidence. Contradictory behavior should update or weaken prior assumptions rather than being ignored.
