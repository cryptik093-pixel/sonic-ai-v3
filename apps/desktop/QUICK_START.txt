SONIC — OMEGA HOUSE PRODUCTION WORKBENCH

1. Extract the entire Sonic-Windows-x64 ZIP into a folder.
2. Open Sonic.exe. Keep the _internal folder beside it.
3. Choose Create MIDI > Generate MIDI & audition.
4. Play the phrase, then export Melody.mid into an FL Studio instrument's Piano Roll.

No Git, Node, Python, terminal or AI subscription is required for local workflows.
The app targets Windows 10/11 x64 and uses Microsoft's WebView2 runtime.

Start here: one bounded next step, matched to your goal and energy.
Create MIDI: four separate parts, one multitrack MIDI, an audition WAV and composition metadata.
Audio & packs: import sources, measure audio and build ZIPs with inventory and checksums.
Prepare a release: caption variants, a demonstration plan and a Shopify draft CSV.
Your outputs: reopen saved results, export files and get a grounded Sonic recommendation.

Core tools use local composition, measurements and workflow rules. They are clearly labeled.
Optional cloud interpretation requires your own configured API key. Save it in Connections.
Its usage is billed by your provider; only use it when you want a model interpretation.

Your new Sonic data is stored under %LOCALAPPDATA%\OmegaHouse\Sonic.
Existing development databases and source packs are not moved or deleted.
Import your audio/MIDI through the app; originals remain unchanged.

The API and MCP run on this computer only. The MCP connection file is private.
The application is a single-operator desktop tool, not a hosted multi-user service.
No live Shopify publication, email sending or ad spending occurs from these workflows.

This build is unsigned. Windows may show the publisher as unknown.
If another local service already uses port 8000, Sonic uses another available port.
Use Connections to save the current MCP address.

MIDI STUDIO (source upgrade; requires a rebuilt desktop distribution)

Select MIDI Studio. Describe supported musical settings and choose Interpret
Direction to review a proposal, or edit the controls directly. Generate saves
selected MIDI parts, audition WAV, Composition.json and Quality_Report.json.
Enable Countermelody for an optional fifth part. Response mode places notes in
lead rests; Parallel mode plays alongside it. Final harmony Resolve lands on I/i;
Loop preserves the progression. Maximum melodic leap controls melodic movement.
Unlock a response Countermelody together with its Melody when revising the lead.

Reuse settings to edit a saved run. Select tracks under its result and choose
Revise selected tracks. Locked notes are preserved exactly. Unlock all parent
tracks to change key, scale, tempo or length. Export all files saves the set.

Audition synthesis is a sketch. Choose your own sounds in FL Studio and judge
melody development, harmony and groove by listening. New native Windows UI and
FL Studio import checks must be completed before declaring release readiness.
