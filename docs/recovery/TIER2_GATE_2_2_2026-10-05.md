## Objective

Move Tier 2 from deterministic in-memory state projection to an auditable local persistence layer without silently converting model output into user truth.

## Persistence contract

Durable SQLite ledger:
- intents
- immutable evidence
- append-only checkpoints
- memory candidates
- Creator DNA candidates
- foresight candidates
- append-only candidate decisions

Every record is owner/workspace scoped.

## Authority boundary

A candidate can be:
`proposed → accepted | rejected → superseded`

Acceptance records an explicit operator decision. It **does not** write to the legacy operational `memories` table, mutate Creator DNA, execute a forecast-driven action, publish commerce changes, or authorize autonomous behavior.

Those materialization/action boundaries are deferred to later gates.

## Integrity rules

- intent IDs cannot be silently rewritten
- evidence is immutable by ID
- checkpoint source-event and sequence collisions fail closed
- candidate evidence must exist in the same intent (or be explicitly global)
- candidate checkpoint provenance must exist in the same intent
- supersession is limited to same intent + same candidate type
- terminal rejected/superseded candidates cannot be resurrected
- API mutation is exposed only beneath the authenticated local `/workbench/api` surface
- all persisted local database files remain excluded from source control
