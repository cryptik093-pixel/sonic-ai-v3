# Quick start
1. Install the complete .vst3 folder as described in README.md and rescan FL Studio.
2. Click Kick and play numeric MIDI note 36, or audition selected pad with 60.
3. PUNCH shapes attack, TONE shapes drum body/pitch, CHARACTER changes material/noise.
4. Change MIDI NOTE to remap each drum. Closed/open hats share choke group 1.
5. Adjust per-drum gain/pan/mute/solo; use SPACE and OUTPUT for the kit.
6. Optional sample: LOAD / RELINK, then raise SAMPLE BLEND above 0.
7. Rename and SAVE KIT; SAVE the FL Studio project as well. Host acceptance status is in the QA report.
