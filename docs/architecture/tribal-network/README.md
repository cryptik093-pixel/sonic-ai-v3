# Tribal Network Architecture Set

**Canonical location:** `docs/architecture/tribal-network/`  
**Authority:** North-Star product architecture + current-build comparison system  
**Date established:** 2026-10-06

This folder preserves two truths at the same time:

1. **What Tribal Network is intended to become** — the stable conceptual / North-Star specification.
2. **What is actually implemented today** — a separate current-state record that must never redefine the North-Star by accident.

## Documents

- `01_TRIBAL_NETWORK_CANONICAL_CONCEPT.md` — canonical concept and conversation capture.
- `02_TRIBAL_NETWORK_TODAYS_WORK_CURRENT_STATE.md` — current-state build record.
- `03_TRIBAL_NETWORK_FUTURE_DESIGN_FEATURE_BLUEPRINT.md` — full future-state design and feature blueprint.
- `04_TRIBAL_NETWORK_CONCEPT_TO_BUILD_BENCHMARK.md` — benchmark and maturity system for comparing current builds to the intended final system.
- `MAGICPATH_HANDOFF.md` — concise product-design handoff for future MagicPath implementation work.
- `source-docx/` — formatted Word-source versions of the same four specifications.

## Core operating rule

> Document the ideal. Build the real. Measure the gap. Preserve the reason. Verify the change. Repeat until the real system and the intended system converge.

## Product boundary

Tribal Network is private-first. It is not primarily a public social profile or vanity network. It is the Tribe's shared creative-intelligence layer: a living system that structures projects, releases, practice, evidence, collaboration, services, assets, career development, and evolving identity while Sonic Intelligence helps the creator preserve freedom in the creative process.

## Documentation discipline

Do not overwrite the North-Star definition with prototype limitations.

When implementation changes:
- update the current-state record;
- record evidence;
- compare against the North-Star;
- classify gaps explicitly;
- amend the North-Star only when the product intent itself has intentionally changed.

Recommended status vocabulary:

`NORTH-STAR` · `DESIGNED` · `IMPLEMENTED` · `VERIFIED` · `PARTIAL` · `BLOCKED` · `DEFERRED` · `REJECTED`
