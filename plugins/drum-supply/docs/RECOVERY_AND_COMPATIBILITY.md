# Recovery and compatibility
The original 0.1.0 source and module are preserved. Before synthesis changes a scoped Git snapshot (844a155) captured original source, optional samples, interrupted sampler changes and recovered files. recovery/pre-synthesis-recovery-manifest.json records paths, byte lengths and SHA-256. recovery/input-assets-manifest.json hashes both input ZIPs, the attached prompt and all 12 original WAV contents. Original external archives were never edited.

Two generated files had all-NUL invalid contents: Source/PluginEditor.cpp and scripts/run-sampler-checks.py. Invalid byte copies remain in evidence/write-recovery. The editor was reconstructed into a complete native JUCE implementation and then updated for eight synthesis slots. The verification runner was recovered as executable Python, then superseded by scripts/run-release-checks.py; its prior name remains a compatibility launcher. Neither was replaced by a blank scaffold. Source and scripts use atomic write/read-back during this recovery.

The user's latest synthesis/product specification supersedes the historical Drum Headquarters sampler brief. Original handoff documents retained in this source tree describe historical requirements, not current release behavior. legacy/0.1.0 is the authoritative sound reference. legacy/0.2.0-sampler preserves the interrupted sampler work. Only the original extended modal synthesis engine is instantiated in the current product; the preserved sampler engine is exercised as an optional-layer regression reference, not a second runtime instrument.

Visible branding and VST3 module filename are now Drum Shot Supply Co. Internal CMake target OmegaDrumSupply, APVTS tree DrumSupply, vendor code OmHs, product code OhDs and bundle ID com.omegahousestudio.drumsupply remain stable. This preserves generated VST3 class identity where JUCE permits. The original first 82 parameter IDs/order are retained. Eight new-slot parameters and per-slot synthesis controls are appended; total 181. department adds Open Hat as its eighth choice, changing normalized selection scaling from 6 to 7 intervals. Old normalized department automation may select a different pad; review it when migrating. Other original parameter ranges are retained. MIDI now uses editable exact note assignments: old alternate GM aliases such as Kick 35 are not implicit; remap the slot or update those notes in migrated projects.

Version-1 state safely migrates global values to the synthesized factory kit, with a visible migration message. Exact legacy rendering is preserved in the original source/module, not promised by this new per-slot gain/impact architecture. Version-2 intermediate sampler state is rejected explicitly rather than silently reinterpreted as synthesized sound. Retain its source recovery snapshot if needed. V3 host-state recall and portable kit tests must pass on the current build before packaging.

No installed VST3 or FL scan database is overwritten by the packaging procedure. Installing this stable-ID successor alongside the legacy plugin can cause host identity collision; archive the old bundle/project first and install only the version you intend to use. This local evaluation has no code-signing certificate or commercial framework entitlement claim. User supplied-sample redistribution was explicitly authorized.
