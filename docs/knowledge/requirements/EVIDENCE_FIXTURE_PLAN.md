# Phase 2 Evidence Fixture Plan

This register defines the next concrete fixture substrate required before audio-domain doctrine can be promoted to validated.

## OH-M04 — Measurement profile
- deterministic loudness/peak/true-peak fields
- sample rate/channel layout
- stereo correlation/mid-side metrics
- analysis version and tolerance metadata

## OH-M02 — Defect taxonomy
- severity
- defect class
- target object
- masker/competing object where applicable
- confidence and evidence source

## OH-M05 — Canonical metadata schema
- project/production/asset IDs
- source/derivative relationship
- key/BPM/sample rate/channels/duration
- rights/license and version fields
- content hash

## OH-M03 — Golden audio fixtures
Minimum fixture classes:
1. controlled clipping vs limiting;
2. kick/808 overlap vs separation;
3. stereo center-authority failure;
4. masking target/masker pair;
5. mono-collapse comparison;
6. export metadata/reference render pair.

No synthetic fixture is accepted as golden until its expected measurements and failure labels are independently verified.
