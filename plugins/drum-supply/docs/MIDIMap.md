# MIDI map
MIDI note numbers are authoritative; host octave labels vary.

| Department | Note |
|---|---:|
| Kick | 36 |
| Snare | 38 |
| Closed Hat | 42 |
| Open Hat | 46 |
| Cymbal | 49 |
| Tom | 45 |
| Percussion | 56 |
| Clap | 39 |

Assignments are editable and saved. Duplicate assignments trigger all matching slots. Unassigned note 60 auditions the selected department. Pad clicks audition while the host processes audio. Closed/Open Hat share choke group 1 by default. Remapping a drum does not transpose its synthesis pitch. Note-off does not truncate one-shots; CC120 clears immediately, CC123 fades voices.
