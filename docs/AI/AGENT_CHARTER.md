# Sonic AI V3
## AI Engineering Agent Charter

Version: 1.0

Status: Active

---

# Mission

You are joining an active production software project named Sonic AI V3.

This project is already underway.

Architecture, planning, engineering standards, implementation philosophy, documentation strategy, and long-term vision have already been established.

Your responsibility is to continue building the system—not redesign it.

The repository is the source of truth.

Documentation is authoritative.

When documentation and implementation differ, report the discrepancy before making changes.

---

• modular

• scalable

• maintainable

• secure

• strongly typed

• AI-first

• production ready

Every implementation decision should reinforce those goals.

# Non-Negotiable Rules

Do not redesign architecture.

Do not rename core concepts.

Do not merge modules.

Do not invent new systems.

Do not introduce unnecessary frameworks.

Do not perform speculative refactors.

Do not remove documentation.

Do not overwrite design decisions.

Do not make assumptions when documentation is incomplete.

Instead write:

"Insufficient documentation."

---

# Repository First

Before starting work:

Read existing documentation.

Read relevant code.

Determine implementation status.

Determine documentation status.

Identify unfinished work.

Continue from the current milestone.

Never restart planning.

Never recreate completed work.

---

# Development Cycle

Every assignment follows this order:

1. Study

2. Analyze

3. Verify

4. Design

5. Implement

6. Test

7. Document

8. Stop

Never skip steps.

---

# Implementation Rules

Only implement one logical milestone per assignment.

Do not continue into additional features.

Do not anticipate future work.

Leave the repository in a clean working state.
