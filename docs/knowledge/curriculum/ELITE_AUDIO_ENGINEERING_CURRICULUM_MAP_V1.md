## Pre-certification controls

The Full-System Audit identifies sixteen controls that must be treated as formal readiness gates rather than optional polish.

| ID | Control | Required outcome |
|---|---|---|
| OH-M01 | Critical-listening calibration | level, duration, breaks, low-volume checks, hidden-reference exercises, safety |
| OH-M02 | Defect taxonomy and severity | controlled defect codes for mud, masking, transient loss, phase, low-end collision, harshness, depth, clipping, export mismatch, device artifacts |
| OH-M03 | Golden audio fixture set | licensed test sessions, stems, broken renders, approved references, answer keys |
| OH-M04 | Measurement profile | meter type, window, sample rate, bit depth, peak convention, LUFS/true-peak method |
| OH-M05 | Canonical metadata schema | production, asset, audio, musical, lineage, QC, rights, commerce, evidence fields |
| OH-M06 | Content-addressed integrity | hashes, replacement, deprecation, derivative invalidation |
| OH-M07 | Rights and license inheritance | source ownership, restrictions, consent, derivative permissions, license propagation |
| OH-M08 | Asset acceptance tolerances | silence, zero-crossing, tails, tuning, stem alignment, completeness, null checks, previews |
| OH-M09 | Rubric / assessor calibration | benchmark submissions and scoring reconciliation |
| OH-M10 | Accessibility | transcripts, captions, diagram alternatives, keyboard access, visual alternatives |
| OH-M11 | Failure recovery and rollback | return to last approved state without destroying source work |
| OH-M12 | Sonic memory governance | provenance, consent, confidence, contradiction, retention, deletion, scope |
| OH-M13 | Agent/tool permission model | allowed reads/writes, approvals, logs, timeouts, idempotency, observable failures |
| OH-M14 | Repository/runtime reconciliation | workspace alignment, boot certification, validation scripts, real capability over shells |
| OH-M15 | Commerce attribution contract | release version, campaign, customer action, payout/refund, experiment identity |
| OH-M16 | Faculty operations kit | instructor guide, resets, turnaround, appeals, integrity, credential issuance |

## Revised delivery phases

1. **Doctrine lock** - completed as the First Edition publication and LMS architecture.
2. **Fixture production** - create the golden audio corpus and resettable labs.
3. **Schema and rights** - version metadata, defect codes, events, lineage, QC, and rights contracts.
4. **Faculty calibration** - benchmark grading, appeals, accessibility, assessor reliability.
5. **Pilot cohort** - run T1-T2 with measured completion and defect data.
6. **Sonic instrumented loop** - ingest approved course events, evidence, memory candidates, and critic scores through explicit contracts.
7. **Master certification** - run T3-T4 capstones and oral defenses.
8. **Evolution and payout** - compare cohorts, product usage, asset quality, and commercial outcomes without false causality.
